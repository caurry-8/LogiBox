# LogiBox

**物流工程分析工具箱 / Logistics Analytics Toolkit**

LogiBox 使用 Python、PySide6 和 pandas，将库存分类、需求波动分析与库存模型整合到本地桌面工作台，面向物流工程学习、库存分析和业务辅助判断。

当前应用版本标记为 **3.4.0**（见 `core/config.py`）。本文描述当前代码，包括决策摘要和决策工作台；这些功能不代表均已包含在历史 `v3.4.0` 标签中。

## 功能

| 模块 | 当前能力 |
| --- | --- |
| 工作台 | 数据概览、分析状态和页面快捷入口 |
| 数据中心 | 导入 CSV / XLSX / XLS，预览、质量检查、加载示例、导出当前数据；CSV 尝试识别 UTF-8、GB18030、Big5 编码 |
| ABC 库存分类 | 按选定数值字段降序计算累计占比，默认以 80% / 95% 为分类边界；支持年需求量 × 单价生成“年消耗金额”，展示分类贡献及 Pareto 图 |
| XYZ 需求稳定性 | 根据至少两个历史需求周期的变异系数 CV 分类，默认 X / Y 阈值为 0.10 / 0.25；展示有效分类覆盖情况及字段语义风险 |
| ABC × XYZ | 按唯一关键字段合并两类结果，展示九宫格热力图、占比和静态管理策略；可按单元筛选明细，导出 Excel（明细与策略双工作表）或 CSV |
| EOQ | 由手动输入的年需求量、订货成本和单位持有成本计算经济订货批量、订货周期及成本 |
| 安全库存 / ROP | 由手动输入的平均需求、标准差、交期及 Z 值计算安全库存和再订货点 |
| 决策工作台 | 综合已有 ABC、XYZ、矩阵及数据质量，展示可决策状态、关注优先级、重点 SKU、风险单元和下一步建议 |
| 报告中心 | 读取已有数据与分析结果，生成 Word（`.docx`）报告 |

数据质量检查提供阻断、警告、提示级问题，包括空数据、缺失单元格、可识别 SKU 字段的空值或重复值、负数等。周期相关规则依赖调用方明确传入的周期列，不会仅凭“数值列”判断其业务含义。

Word 报告包含七章：数据概况、ABC、XYZ、交叉矩阵、EOQ、安全库存与再订货点、分析建议。报告披露质量问题、XYZ 字段语义风险和分析覆盖情况；未运行的分析显示尚未完成。**目前不包含决策工作台的结构化决策摘要。**

## 安装与启动

以下为 Windows PowerShell 示例，需预先安装 Python 3.10 和 Git。命令提供使用步骤，不代表干净环境安装已验证通过；当前验证状态见下文。

```powershell
git clone https://github.com/caurry-8/LogiBox.git
cd LogiBox
py -3.10 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

如果目录已存在，进入现有项目目录操作；已有 `.venv` 时不要重复创建或覆盖。也可以使用 Python 3.10 解释器的完整路径代替 `py -3.10`。

`requirements.txt` 声明 PySide6、pandas、openpyxl、xlrd、matplotlib、python-docx 和 pytest，目前未固定版本。安装需要访问 PyPI 索引和文件下载服务；运行应用会写入 `logs/logibox.log`。界面和图表优先使用中文字体，实际显示取决于系统已安装字体。

## 使用流程与功能边界

1. 在数据中心导入自己的数据，或加载仓库示例，先查看质量问题。
2. 在 ABC 页面选择分析字段，或选择年需求量与单价生成价值字段；在 XYZ 页面明确选择实际历史需求周期。
3. 完成 ABC 和 XYZ 后，在矩阵页面选择唯一匹配字段并生成矩阵。
4. 在决策工作台查看关注项；按需独立计算 EOQ、安全库存，再到报告中心生成 Word 报告。

理解结果时请注意：

- **EOQ 和安全库存是全局单次参数计算，没有逐 SKU 批量结果。**决策层仅记录这两个模型是否运行，不将其结果套用为每个 SKU 的补货量或安全库存。
- **决策层与矩阵策略是可解释的规则建议，**不提供自动预测、全局最优库存方案或自动采购执行。质量阻断或必要分析不足时，决策层不生成正常决策项；未有效分类的记录不进入矩阵决策项。
- ABC 当前将部分缺失或无法转为数值的值按零处理；XYZ 区分真实零需求、缺失值与无穷值，缺失或非法记录不参与正常分类。XYZ 使用总体标准差（`ddof=0`），真实全零需求约定 CV 为零；无有效分类数据时平均 CV 不以零冒充。
- XYZ 对可疑字段选择提示风险，但允许计算。数值列可被选择，不代表单价、年需求量等字段适合作为周期序列。
- 矩阵使用关键字段的一对一内连接，拒绝重复键；覆盖率以匹配后的输入集合为基础，各单元占比基于实际参与矩阵分析的集合，不能直接理解为全部原始数据的覆盖率。
- 数据与分析结果由内存中的 DataStore 共享；重新导入或清空会清除分析结果。修改分析参数后应依次重算相关分析和矩阵，再查看决策或导出报告。
- 模型输入的需求、成本、交期和计量单位需由使用者确认一致，正式业务决策还需结合供应商交期、业务周期与仓储条件复核。

## 示例数据

`data/sample_inventory.csv` 包含 10 行、10 列，可从数据中心加载。

| 字段 | 用途与注意事项 |
| --- | --- |

| `年需求量` | 年度需求数值，可用于 ABC，或与单价相乘；不是月度历史周期列 |

## 项目结构

```text
main.py                 应用入口、字体与异常处理
core/                   版本配置、页面定义、主题加载与日志
ui/                     主窗口、页面注册与导航
pages/                  数据、分析、决策、报告等页面
utils/                  分析算法、质量与字段规则、DataStore、图表和输出
widgets/                可复用指标卡
styles/                 QSS 界面样式
data/                   示例 CSV
tests/                  pytest 回归测试与公共 fixture
requirements.txt        当前依赖清单（未固定版本）
pytest.ini              测试配置
```

主窗口创建共享 DataStore；页面调用分析模块并写回结果，通过 Qt 信号刷新相关展示。决策判断集中在 `utils/decision_utils.py`，文案位于 `utils/decision_text.py`；报告生成位于 `utils/report_utils.py`。
